# Cross Format Repurposer (Subagen 1 Konten Multi-Format)

## Tujuan
Mengubah 1 ide konten (berita/karaoke) menjadi paket distribusi multi-format lengkap secara instan tanpa mengulang riset dari nol.

## Output 5 Format Baku
1. **Script Video Vertikal (8-15 Detik)**: Narasi voiceover padat + instruksi visual untuk Reels/Shorts.
2. **Thread X/Twitter (3 Tweet Runtut)**: Hook pembuka, bedah fakta, dan ajakan diskusi.
3. **Pesan Siaran Telegram**: Ringkasan berita elegan dengan emoji rapi & tautan portal.
4. **Caption Instagram/Facebook**: Storytelling mengalir + hashtag niche.
5. **Snippet Metadata SEO**: Judul meta & deskripsi ringkas untuk Google Search.

## Skrip Terkait
- Executable: `/root/tools/cross_format_repurposer.py`

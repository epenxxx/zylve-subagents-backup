# Skill: /new (Fresh Topic / Task Reset)

Skill ini menyinkronkan fungsionalitas perintah CLI `/new` ke dalam antarmuka chat.

## Alur Kerja Saat Perintah `/new` Dipanggil:

1. **Simpan Progres Sesi Aktif**:
   - Pastikan setiap catatan penting atau progres tugas terakhir telah terdokumentasi di `memori.md`.

2. **Reset Fokus Agen**:
   - Nyatakan bahwa Cimoy siap menerima instruksi atau topik proyek baru dari awal dengan memori jangka panjang tetap utuh.
